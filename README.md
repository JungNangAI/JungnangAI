# 중랑 새내기 첫장

서울특별시 중랑구 신규 공무원을 위한 실무 안내 사이트입니다. 첫 출근부터 예산·계약·지출, 복무·후생복지까지
**중랑구 조례·규칙과 현행 법령 원문으로 대조한 카드 144장**과 매일 바뀌는 **오늘의 5문제**를 담았습니다.

- 사이트: https://jungnangai.github.io/jungnangAI/
- 만든 이: 중랑구청 주무관 송재철 (중랑구판)
- 원작: 화성특례시 AI스마트전략실 빅데이터팀 hwaseong-kb · 광진구판: 딴짓하는 류주임

## 구성
- `index.html` 한 파일에 화면·검색·카드·퀴즈가 모두 들어 있습니다. 서버나 설치가 필요 없습니다.
- 카드 데이터는 `index.html` 안의 `const DATA`, 오늘의 5문제는 `const QUIZ`, 개정 감시 목록은 `const LAW_WATCH`입니다.
- 체크리스트·스크랩·퀴즈 기록은 각자 브라우저에만 저장됩니다(개인정보를 서버로 보내지 않음).
- 캐릭터 랑랑이·똘배는 중랑구 캐릭터입니다.

## 업데이트
- 매주 월요일 아침, 카드가 근거로 쓰는 법령·조례 56건의 개정 여부를 법제처 원문과 대조합니다.
- 개정이 있으면 해당 카드와 연결된 퀴즈를 고쳐 이 저장소에 반영하고, 고친 카드에는 담당부서 확인 전까지 '확인 필요' 도장이 붙습니다.
- 페이지 하단에 마지막 점검일이 표시됩니다.

## 주의
이 사이트는 신규자의 이해를 돕는 참고 자료입니다. 실제 업무 처리는 항상 현행 법령·조례 원문과 소관부서 안내를 따르세요.
